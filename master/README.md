# Descrição do nó Master:

Utilizamos o software OpenPLC para tornar o ESP32 mestre efetivamente em um CLP funcional com programação em Ladder.

Todos os procedimentos de instalação e configuração foram realizados segundo o website abaixo:
https://autonomylogic.com/

O OpenPLC Editor foi inicialmente instalado na máquina de um dos membros com o OpenSuse Linux (Slowroll).

O OpenPLC Runtime foi instalado diretamente no ESP32 MASTER através da funcionalidade de instalação para microcontroladores que se encontra disponível no OpenPLC Editor.
